## 二、功能说明（new-api 模型调用分析看板 → octopus 画风版）

new-api 原版（截图）：顶部 Tab（模型调用分析/分流/用户统计）+ 偏好设置弹窗；
"模型调用分析" Tab 内：总数/总 naveg/总 TOKEN/平均 RPM/平均 TPM 五指标卡 →
性能概览（成功率/平均延迟/吞吐 + 分模型健康条）→ 消耗分布（堆叠柱/面积可切换）。

octopus 画风版（按 NM-CUR-025 裁决降级为首页单块 `ModelMonitor`，已实现未提交）：

1. **五指标卡**（与 `Total` 同卡片画风：`rounded-3xl bg-card border` + 图标方块）：
   总调用 / 总费用 / 总 Token / 成功率 / 平均延迟，均由 `channel/stats` 快照派生
2. **模型健康行**（语义照截图，样式用本仓徽标）：成功率着色圆点（≥95 翠绿/≥80 琥珀/其余玫红）+ 模型名 + 百分比
3. **分模型明细表**（Top 8，按调用量倒序）：模型 × 渠道 → 调用/成功率/费用；渠道名支持顶栏模糊开关
4. **消耗分布**（与趋势图同 recharts 栈、同 `--chart-*` 色系）：按费用 Top 8 横向条形
5. **空态**：无调用数据时只显示标题 + 副标题 + `noData`，不占多余空间

数据口径：成功率 = success/(success+failed)；平均延迟 = wait_time/次数；
全部由 `useChannelStats()` 快照在前端派生（`web/src/api/monitor.ts` 的 `useModelMonitor`），
与首页 Total/榜单同源，不另建表、不新增后端接口（R-spec 落定前）。
`UsageHourly` 小时桶 + `GET /api/v1/stats/usage` 为后续 M-spec 项，不在本任务。
