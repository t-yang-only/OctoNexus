## 2. 疑问裁决（默认口径，避免反复等待）

1. **余额归零粒度：凭据级**。同渠道多凭据互不连坐；只停止关联授权/成员，不关闭整条渠道，不删除数据；手动恢复，不自动抖动恢复。
2. **归零判定：`remaining <= 0`**。低于用户配置阈值属于告警，不等同于自动停用；未知、超时、解析失败不得停用。
3. **均衡默认算法：加权轮询**。权重由健康状态、余额可用性和失败冷却共同决定；最低延迟作为可选策略，不在第一版混入复杂自适应。
4. **号池安全边界：官方账号只允许通过合法官方授权/官方接口接入**。不做验证码绕过、非官方逆向、共享 Cookie 导入或规避平台风控。
5. **手动登录跳转页：只做一次性短期 state/code**，服务端不接收或持久化明文密码；NA/S2 登录在用户浏览器完成，回调只交换短期授权结果。
6. **协议转化：先做已有 OpenAI Chat ↔ Anthropic Messages 的矩阵回归**，再接官方账号适配器；每个方向分别验证请求、流式事件、错误和 usage，不把“能连通”当作转换完成。
7. **隔离测试：使用仓外 `D:\奇怪的软件\octopus-本地数据\数据备份(勿提交).json` 的副本**，新 SQLite/新 admin/新端口；测试结束销毁隔离库，不导入当前生产库，不改备份源文件。
8. **日志分析与修复分离**：T-log-002 先只读给出证据、复现条件和修复建议；确认后另开 fix 任务，避免直接把线上日志推断写成代码事实。
