## 3. 禁跳规则（写在车道显眼处）

1. **顺序硬约束**：W0 没全过门，任何 agent 不得开 W1 任务；同理 W1→W2→W3。
2. **车道内顺序**：车道表顺序即执行顺序；完成本车道当前任务前不得领下一个。
3. **改道审批**：换车道/换任务必须先在登记台登记"改道原因+目标车道"，等 137 线（本会话）或用户批准，未批不改。
4. **任务冲突**：想领的任务已被认领 → 登记等待，不抢、不并行重做、不另开重复行。
5. **阻塞上报**：前置灭失/接口不明/权限不足 → 停手，登记阻塞说明，等调度裁决；不得"顺手做别的"。
6. **红线**：不改他人未提交代码；备份/日志文件仓外只读；密钥/明文 token 不落库不进日志；不复制 `reference/` 代码。
