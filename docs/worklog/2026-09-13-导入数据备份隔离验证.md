## 执行操作

1. `go build -o $TEMP\octopus-testbuild.exe .`（63.5MB），拷贝到 `D:\Temp\oct-import\octopus.exe`
2. 隔离空库启动：`octopus.exe start`，工作目录 `D:\Temp\oct-import`；
   日志 `Config file not found, creating default config / initial user: admin`
3. 登录冒烟：`POST :3303/api/v1/user/login`（body 经 UTF-8 文件传入，PowerShell 管道中文引号曾导致 400，
   定位为 shell 编码问题而非后端 bug）→ 200 + cookie 落盘
4. 空库 fetch-model 烟雾（`probe:false`，目标 `http://127.0.0.1:9` 不可达）：
   → 502 且 message 同时携带 openai/anthropic 两侧原文，证明探测双侧并发与错误透传正常
5. 导入备份：`POST :3303/api/v1/setting/import`（`Content-Type: application/json`，
   `--data-binary @数据备份(勿提交).json`，仓库外原文件只读引用）→ **HTTP 200**
6. 导入后拉取：`GET /api/v1/channel/stats`、`GET /api/v1/group/list`、`GET /api/v1/model/list` 均为 200
7. 详情与探测链路：`GET /api/v1/channel/detail/1`（53HK，`api.x5m5x.com`，1 凭据 default）→ 200；
   用 DUMMY key 调 `fetch-model` → 上游回 `401 INVALID_API_KEY`（双侧原文透传），证明探测链路打通
8. 直接打上游：`POST https://api.x5m5x.com/v1/chat/completions`（DUMMY）→ `401 {"code":"INVALID_API_KEY"}`，
   证明上游可达、鉴权层正常，401 来自上游而非本程序
9. 自动分组抽查：`53HK/Auto-Model` 含 1 成员（53HK/Auto-Model/default，protocols=14，available=true）
10. 停服：`Stop-Process -Name octopus`，确认进程已退出
