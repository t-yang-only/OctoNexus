# T-acct-003 Token/Key 健康监控四类探测（NM-CUR-139）

- 认领：`docs/agents/claims/2026-09-13-cursor-local-T-acct-003.md`；ledger T-acct-003 todo→doing
- 范围：只做只读探测客户端 + 单测；不含 UI、不含定时任务、不落库；
  Admin-costs 按登记台备注留权限门不实现（`AdminCostsProbeEnabled=false`）
- 口径：沿用 health 包只读采集规范（30s 超时 / 1MiB 限读 / 失败 Healthy=false 不阻断转发）

## 1. 实现（`internal/health/` 新增两文件）

- `probe_token.go`（形状与口径）：
  - `ProbeKind` 五类常量：`na_token` / `s2_token` / `openai_key` / `anthropic_key` /
    `admin_costs`（占位）；`ProbeResult`（kind/base_url/healthy/status_code/latency_ms/error）；
  - `AdminCostsProbeEnabled = false` 权限门：关闭时 Admin-costs 探测直接返回说明性错误，不发请求；
  - `ValidProbeKind` 类别校验。
- `probe_token_client.go`（探测器）：
  - `ProbeToken(ctx, kind, baseURL, token, useProxy)` 单入口；
  - NA-Token：`GET /api/user/self` + `Authorization: Bearer`（验证 token 有效与额度可见，读侧）；
  - S2-Token / OpenAI-Key：`GET /v1/models` + `Authorization: Bearer`；
  - Anthropic-Key：`GET /v1/models` + `x-api-key` + `anthropic-version: 2023-06-01`；
  - 代理开关复用 `rhttp.Proxy()/Direct()`；2xx 即健康，响应体限读后丢弃。

## 2. 测试（`probe_token_test.go`，httptest 桩，全过）

- 类别校验：五类合法 + 4 类非法拒绝；
- 四类主路径：各自鉴权头逐项断言（Bearer / x-api-key / anthropic-version）、
  2xx 健康、401 失败、空 token 失败；
- Admin-costs 权限门：不发请求（status_code=0）+ 说明性错误；
- 未知类别直接失败。
