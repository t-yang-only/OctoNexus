## 3. 不应直接判为业务 Bug 的项目

1. `context canceled`：请求日志显示客户端取消，Caddy 也显示 incomplete response；没有上游错误证据，不能直接修重试。
2. 历史渠道失败率：缺少时间窗口、模型/协议维度，不能据此自动停渠道。
3. HTTP 400：更像探针 payload/协议契约或上游参数错误，不等价于网络假死；需要单独复现。
4. UTF-8 乱码：属于采集/展示链编码问题，不代表服务端业务数据损坏。
