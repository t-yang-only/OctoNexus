## 2. 发现的 bug 与修复

- 现象：`ProbeToken` 只看 HTTP 状态码，`Healthy=true` 前把响应体直接 `io.Copy(io.Discard,...)`
  丢弃。反代/网关返回 2xx HTML 登录页或 200 空体时，凭据实际无效也会被判健康。
- 与仓库既有口径对照：`check_protocol_probe.py` 对渠道探测明确要求
  "2xx must also yield JSON-looking body (anti 200-HTML)"，健康监控理应同口径。
- 修复：`probe_token_client.go` 改为 1MiB 限读后经 `probeResponseLooksValid`
  做 JSON 可解析性校验（四类均要求合法 JSON，不校验业务字段以兼容不同上游 schema），
  非 JSON/空体判 `Healthy=false` 并记错误。
- 回归测试：`TestProbeTokenRejectsNonJSON` 覆盖 2xx HTML 错误页与空体两种误判源；
  原 `TestProbeTokenKinds` 桩响应补 JSON 体以匹配新口径。
