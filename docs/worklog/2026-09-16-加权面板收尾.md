# 面板收尾：渠道计费字段 + 加权权重设置界面

日期：2026-09-16　执行：dsh-local（NM-DS-020 / 台账 T-weight-003）
上游：`docs/worklog/2026-09-16-加权综合选路.md`（五维机制）、`docs/worklog/2026-09-16-加权综合-计费维度.md`（计费四维）

## 1. 补了什么

前两阶段把加权综合选路做完了，但**只能通过接口配置**（渠道计费字段、9 个维度权重、包月用尽动作）。这一轮把它们搬上面板：

**渠道编辑对话框 → 高级配置** 新增：
- 计费方式下拉：未知 / 按量计费 / 按次计费 / 包月；
- 四个数字输入：计价倍率、按次单价、包月额度、包月已用；
- 一段说明：这些用于加权选路折算「实际有多贵」，0 或留空表示未知（未知不做惩罚），余额不需要填、由余额扫描自动带入。

**设置页 → 系统 → 路由参数** 新增「加权综合选路权重（weighted 模式）」区块：
- 9 个维度权重输入（成本 / 质量 / 延迟 / 在途 / 近期消耗 / 倍率 / 按次 / 余额 / 包月余量），0..100，失焦即保存；
- 一个下拉：包月用尽的处置（降权 / 剔除）；
- 说明里写清「0 表示该维度不参与，不必凑满 100」。

实现上用了一个自包含的 `WeightSettingField` 小组件（自己读设置、自己保存并 toast），
避免在 `System.tsx` 里为 10 个键再抄一遍父组件的 state/ref/同步样板；`SettingKey` 枚举同步补了 10 个键，
三语（简体 / 繁体 / 英文）文案一并补齐。
