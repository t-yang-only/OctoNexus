## 骨架映射要点（Python → Go）

| litellm (Python) | go-converter 对应 | 说明 |
|---|---|---|
| `litellm/__init__.py` completion() | `litellm-go/litellm.go` | 门面 + SplitModelProvider |
| `llms/base_llm/*` 多继承 mixin | `providers.go` 接口组合 | Provider/Streaming/Embedding/TokenCounter |
| `exceptions.py` 异常层级 | `errors.go` | `*Error` 包装 + IsRetryable |
| `router.py` + `router_utils/` | `router/router.go` | 加权随机/LeastBusy/重试/429冷却/fallback 链 |
| `llms/openai/` `llms/anthropic/` | `providers/openai`、`providers/anthropic` | 真实 HTTP 调用可用；anthropic 含响应归一 |
| `proxy/spend_tracking/` + budget | `budget/` | 内存版闸门+记账，接口即替换点 |
| 回调列表 callbacks | `logging/` | Sink 接口异步分发，panic 隔离 |
| `proxy_server.py`(FastAPI) | `proxy/server.go` | net/http，/v1/chat/completions、/v1/models、/key/generate、/health |
| `auth/user_api_key_auth` | `proxy/auth.go` | 虚拟 key 签发/校验（内存 map 版） |
