- 用户指令（本轮原话）：项目后面部署到 **Ubuntu** 上，**不需要打包 exe**

## 裁决（供各 Agent 对齐）

| 项 | 裁决 |
|---|---|
| 构建产物 | 只出 **linux/amd64 单二进制 + 前端静态资源（已内嵌 `static/`）**；CI/文档不再提 Windows exe、`.exe` 后缀、`GOOS=windows` 交叉编译 |
| 本地 Windows 开发 | 仅 `go run` / `go build`（默认 windows）跑通即可；不再产出可分发的 exe 工件，进 `.gitignore`（`*.exe`） |
| docker-compose | 端口映射按双端口更新：`3303:3303`（admin）+ `1234:1234`（relay），替换残留的 `8080:8080`；卷挂载示例路径改为 Linux 风格 |
| systemd（后续） | Ubuntu 部署用 systemd unit 模板（`docs/deploy/octonexus.service`，待实施时补），`WorkingDirectory=/opt/octonexus`，`data/` 落盘同目录 |
| 发版流程 | 以 CI `build`（ubuntu-latest）产物为准；手动发版命令统一为 `GOOS=linux GOARCH=amd64 go build` |

## 影响面（待实施，不在本轮）
