## 2. new-api 实现要点（已精读，移植时逐文件重写，禁整片复制/AGPL 污染）

**后端**（Go，可直接借鉴思路）：
- `pkg/perf_metrics/metrics.go`：`RecordRelaySample(RelayInfo, success, outputTokens)` —
  转发完成处埋点；`hotBuckets sync.Map` 按 `{model,group,bucketTs}` 聚合；
  指标：latencyMs / ttftMs（流式首包）/ success / outputTokens / generationMs。

  `/api/perf-metrics/summary?hours=` 与分模型查询（hours 上限 30d）。
- 配置：`setting/perf_metrics_setting/config.go`（Enabled/FlushInterval/Retention 开关）。
